# Developer Portfolio Generator

A responsive portfolio website generator inspired by the internship project list.

## Features
- Edit name, title, introduction, skills, project and contact details.
- Live preview updates as you type.
- Switch between dark and light colour themes.
- Print or save the portfolio as a PDF from the browser.

## Run
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Edit the fields in the left panel.
4. Use **Switch theme** to change the portfolio palette.
5. Use **Print / Save PDF** to export.

## Technology
HTML, CSS and vanilla JavaScript. This is a standalone frontend demo; it does not include a backend or hosted deployment integration.
